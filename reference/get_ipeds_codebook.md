# Get the cori.data.ipeds variable codebook

Returns documentation for every variable available via
[`get_ipeds()`](https://ruralinnovation.github.io/cori.data.ipeds/reference/get_ipeds.md)
and
[`get_ipeds()`](https://ruralinnovation.github.io/cori.data.ipeds/reference/get_ipeds.md).
Covers the three IPEDS surveys this package harmonizes: Institutional
Characteristics, Completions, and Graduation Rates, 2010 to present.

## Usage

``` r
get_ipeds_codebook()
```

## Value

A data frame with columns: `variable`, `raw_variable`, `label`, `unit`,
`survey`, `level`, `notes`, `codes`. `raw_variable` is the original NCES
column name, as stored in the `data_raw` layer on S3; it is empty for
derived county-level variables. `codes` decodes the categorical
variables – a `"1 = Public; 2 = Private not-for-profit"` string – and is
empty for the rest.

## Details

Use `level` to separate the two output levels: `"institution"` variables
appear in
[`get_ipeds()`](https://ruralinnovation.github.io/cori.data.ipeds/reference/get_ipeds.md)'s
institution-level output, `"county"` variables in
[`get_ipeds()`](https://ruralinnovation.github.io/cori.data.ipeds/reference/get_ipeds.md)'s
tidy output, and `"both"` marks the join keys present in every table.

`notes` records vintage caveats – which years a variable covers, NCES
column renames, and taxonomy changes – so cross-year comparability is
documented alongside the variable rather than in separate prose.

Much of IPEDS is categorical, and the institution-level output returns
those columns as the bare integers NCES publishes. `codes` carries the
value labels for them, transcribed from the NCES data dictionary
workbooks, so a `sector_code` of 4 can be resolved without leaving the
package. Only codes that actually occur in this package's output are
listed. NCES sentinel values (-1, -2, -3) are converted to `NA` during
the ETL and so do not appear.

## See also

[`get_ipeds()`](https://ruralinnovation.github.io/cori.data.ipeds/reference/get_ipeds.md),
[`get_ipeds()`](https://ruralinnovation.github.io/cori.data.ipeds/reference/get_ipeds.md)
